# Compatible-release pins (~=) instead of open-ended >= — allows patch
# updates but blocks the unannounced major-version jumps that broke the
# PaddleOCR integration repeatedly (see mini-services/paddleocr-service).
#
# Deployment target is Python 3.11 (built from source on the OCI box —
# Ubuntu 20.04's system Python 3.8 and deadsnakes' Focal builds are both
# EOL and can't satisfy several of these packages' current Python floors).
# All pins below verified via `pip download --python-version 3.11
# --only-binary=:all:` to both exist AND resolve together as a set —
# individual packages resolving in isolation isn't enough; opencv-python
# 4.13.x requires numpy>=2, so a numpy pin capped for 3.8 compatibility
# (numpy<1.25) creates an unsolvable conflict here even though every
# package individually installs fine on its own.
edge-tts~=7.2.8
openai~=2.7.1
Pillow~=11.3.0
opencv-python~=4.13.0
numpy~=2.1.0
# NOTE: torch/torchvision are installed SEPARATELY by setup.sh via
# --index-url https://download.pytorch.org/whl/cpu (CPU-only build).
# The versions below just record the minimum — pip will skip them
# if the CPU build already satisfies the constraint.
# Do NOT add --extra-index-url here or pip may pull a GPU build.
torch>=2.0.0,<3.0.0
torchvision>=0.15.0,<1.0.0
ultralytics~=8.0
huggingface-hub~=0.20
